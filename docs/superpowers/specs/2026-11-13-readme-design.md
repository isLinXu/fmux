没有模型能否试用、如何接入真实模型、有哪些限制。

较长的请求生命周期、进程/内存原理、发布历史与测试矩阵

## 事实与示例约束

- 不将 deviceNotEligible 推断为某个区域或账号原因。
- 不承诺绕过 Apple Intelligence/PCC 限制或修复系统 fm 的所有功能。
- 不承诺支持所有服务器、所有模型或完整 OpenAI API。
- 本地后端保持数据在本地；配置远程 target 后请求会发往对应服务器。
- 预算基于估算并允许超预算，不是硬内存上限；预算失败/并发修复尚待实施。
- 结构化输出/工具/视觉依赖具体后端与模型；
  MLX prompt 降级不等于原生 JSON Schema 保证。
- TTFT 是校验后到首次文本/工具输出写入耗时，
  不能仅用 TTFT 区分冷启动与隐藏推理等原因。
- 快速开始的模型 ID 是示例，需替换为实际已安装且被 backend 暴露的名称。
- SDK/fm 仅调用已有端点；fm 的配置方式明确区分单次选择与持久化默认值。
- 不给出虚构速度、容量或测试数，不把未提交源码的结果当成发行包保证。
