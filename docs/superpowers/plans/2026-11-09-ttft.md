# TTFT Implementation Plan

> **For agentic workers:** Use executing-plans inline, task-by-task. Preserve the dirty optimization branch; do not commit or replace the running service.

**Goal:** TTFT 包含准入、准备与 fallback，以首个成功写出的文本/工具函数输出为终点。

**Architecture:** 在 Validate/Normalize 后取一次请求起点，显式传递到各 target。
保留 per-target duration 起点；在 SSE 写入成功且 chunk 含有效输出时记录一次 TTFT。

**Tech Stack:** Go time/context、httptest、现有 gate/metrics、race。

```go
func chunkHasOutput(ch *ir.Chunk) bool {
    for _, choice := range ch.Choices {
        if choice.Delta.Content != "" {
            return true
        }
        for _, call := range choice.Delta.ToolCalls {
            if call.Function.Name != "" || call.Function.Arguments != "" {
                return true
            }
        }
    }
    return false
}
```
